# Technical-pilot sessions (never official)

Sessions of participant IDs starting with `PILOT` (for example `PILOT01 / T1`) are imported here with `calib_eval_data.py import <export> --raw docs/calibration-comparison/data/pilot --allow-pilot`. They check the procedure, the app and the tools, never the candidates. Everything in this folder except this README is ignored by Git and is never part of an official analysis or result.
