# Archived per-position figures: ANNA / CALIBRATION_A (`761b3d19`)

These are the original per-position views of the **first exploratory candidate A recording**, session
`eval-20261115T093800Z-761b3d19` (complete, not official: its label is outside the collection plan). They show two
figures per head-position block: target vs mean estimated gaze, and mean target error by pass. They were the default
figures until the per-session summary view
([`../../draft/ANNA_CALIBRATION_A_761b3d19/`](../../draft/ANNA_CALIBRATION_A_761b3d19/)) replaced them, and are kept
for anyone who needs the per-position detail.

Nothing in them was changed. On 2026-11-15 the 12 image files were moved byte for byte from
`docs/calibration-comparison/figures/`, and their plot tables and manifest from `docs/calibration-comparison/data/derived/`
to [`provenance/`](provenance/). The paths recorded in `provenance/figures-manifest.json` are those original locations;
its SHA-256 values match the files here. They were generated by `calib_eval_figures.py` 1.0.0 (matplotlib 3.11.2,
numpy 2.5.4) from the unchanged analyzer output `data/derived/summary.json`.

Provenance: [`provenance/figures-manifest.json`](provenance/figures-manifest.json) (inputs, versions, shared scales,
checksums), [`provenance/figure_presentations.csv`](provenance/figure_presentations.csv) (plotted value per
presentation) and [`provenance/figure_target_centroids.csv`](provenance/figure_target_centroids.csv) (plotted mean
estimate per block and target).

How to read them: the gaze map draws the screen to scale (x to the right, y downward); blue crosses are the 16 targets,
orange dots the mean estimated gaze per target in that block (the two passes' presentation centroids weighted equally),
with arrows from target to estimate. Each bar of the error chart is one presentation's mean sample error, pass 1 solid
and pass 2 hatched, on a shared axis of 0 to 0.75; the dashed 0.10 line is only the error part of the per-presentation
success rule.

To regenerate them (the per-block view of the current tool reproduces these image bytes exactly; write into a scratch
directory, never into this archive):

```powershell
python -B docs\calibration-comparison\tools\calib_eval_figures.py --view per-block --summary docs\calibration-comparison\data\derived\summary.json --selection docs\calibration-comparison\data\analysis-inputs.json --derived <scratch>\derived --figures <scratch>\figures
```
