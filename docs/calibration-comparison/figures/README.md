**Aggregation.** Each of the 16 targets has six presentations (three head-position blocks × two passes), matched by
grid position. The circle is the equal-weight mean of the eligible presentations' centroids; the bar is the
equal-weight mean of their mean sample errors (never the distance from target to averaged position). With fewer than
six eligible presentations a target is marked partial (hollow circle, hatched bar, count shown); in B1 all 96 are
eligible. Units: x / display width and y / display height (0.10 = 108 px horizontally, 231.6 px vertically on the
1080 × 2316 px display). The y axis of the error chart runs from 0 to 0.5 and grows in steps of 0.05 only when a bar
needs more room (B1: largest bar 0.22). The view is descriptive and can hide differences between head positions; the
per-block verdicts are unchanged and are listed in the captions.

Regenerate from the repository root with matplotlib 3.11.2 and numpy 2.5.4
([`../tools/requirements-plot.txt`](../tools/requirements-plot.txt)):

```powershell
python -B docs\calibration-comparison\tools\calib_eval_figures.py --summary docs\calibration-comparison\data\derived\summary.json --selection docs\calibration-comparison\data\analysis-inputs.json --figures docs\calibration-comparison\figures\final
```

The output is deterministic for the same inputs and library versions.
